# Security

Report a vulnerability privately with GitHub's **Report a vulnerability** button on this repository's Security tab, or on [the provider's](https://github.com/plotwork-official/terraform-provider-plotwork/security). Please do not open a public issue.

Never commit an API key: set `PLOTWORK_API_KEY` in your shell or CI secrets. `terraform.tfvars` and state files are ignored by git here for the same reason.
